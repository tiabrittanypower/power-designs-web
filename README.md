# Power Designs Web

Marketing site for **Power Designs** (South Africa), live at [powerdesign.co.za](https://powerdesign.co.za/).

Static HTML/CSS/JS site with blog, services, pricing, contact, and Hostinger-oriented `.htaccess`. Built as a real client-facing web presence (not a tutorial demo).

## Stack

- HTML, CSS, vanilla JavaScript
- Progressive enhancement / simple front-end patterns
- Deployed on Hostinger (production)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx --yes serve .
```

## Screenshots

Add a `docs/screenshots/` folder with homepage / services captures if you want visuals on the repo landing page.

## Notes

- This publish tree is scrubbed of browser login profiles and local deploy scratch folders.
- No server secrets are required to view the static site.
